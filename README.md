# Task Manager

A simple task manager built with HTML, CSS and JavaScript for the Web Development Week 04 task.

## Features

- Add tasks (empty tasks are not allowed)
- Mark tasks as completed
- Delete tasks
- Pending task counter
- Filters: All, Pending, Completed
- Tasks are saved with localStorage, so they stay after refreshing

## How to run

Open `index.html` in any browser.

## Built with

HTML, CSS and JavaScript
